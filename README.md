# CareerKit UK

A zero-dependency, Vercel-ready MVP for a UK-first career toolkit.

## What is included

- Five user pathways: career change, freelancing, personal branding, management and portfolio careers
- Five interactive tools:
  - Freelance Rate Planner
  - Portfolio Career Planner
  - Career Change Readiness Score
  - Personal Brand Statement Builder
  - New Manager 30/60/90 Plan
- Product/monetisation architecture for expanding the original long-form guides into a searchable resource
- Responsive design with no framework, build step, database or API keys required

## Deploy

Import this repository into Vercel. It is a static site, so no environment variables or build command are required.

## Product direction

The initial guides are treated as the knowledge base, not as five isolated products. The intended flywheel is:

1. High-intent search pages and useful interactive tools
2. Related original guides and downloadable resources
3. Carefully matched affiliate/commercial resources
4. Display advertising only once traffic is meaningful
5. Optional premium toolkit later

## Important content rule

Any factual, tax, legal, employment or fast-changing UK material should be verified against current authoritative sources before publication. The current MVP intentionally avoids making those claims.
